1 Executive Summary & System Purpose

The XortLogix High Level Assistant is an enterprise-grade artificial intelligence platform engineered to bridge the technical divide between complex GoHighLevel CRM infrastructure, custom software development, and senior-level technical solutions architecture.

1.1 The Challenge in GoHighLevel Engineering

GoHighLevel (HighLevel / LeadConnector) has become the dominant all-in-one CRM and marketing automation engine for modern agencies and SaaS enterprises. However, delivering advanced technical solutions on HighLevel introduces severe technical barriers:

  • API Evolution & Deprecation: HighLevel officially deprecated API v1 on December 31, 2025. Standard generic LLMs (such as base ChatGPT) frequently generate broken v1 snippets with legacy endpoints and incorrect header formats.
  • Strict OAuth 2.0 & Token Lifecycles: Multi-tenant HighLevel apps require strict 24-hour token refresh rotation, granular permission scopes, and specific HTTP request headers (Version: 2021-07-28).
  • Dynamic SPA Limitations: HighLevel renders dashboards, contacts, and funnels as a client-side Single Page Application (SPA). Standard static scripts fail because target DOM nodes are rendered dynamically as users navigate.
  • AI Hallucination in Consulting Proposals: When generating technical RFPs or proposals, standard AI models frequently fabricate experience, claim non-existent case studies, or invent metrics, undermining credibility with enterprise clients.

1.2 The Platform Solution

XortLogix High Level Assistant solves these hurdles by providing a unified, multimodal technical co-pilot backed by a factual vector retrieval engine:

Key Innovation: Instead of relying solely on general LLM weights, the assistant interrogates a curated 5,717-chunk ChromaDB vector store representing official REST API v2 docs, OAuth handshakes, and proprietary company frontend code before synthesizing responses.

3.3 The Composite Ranking Equation & Anti-Hallucination Guardrails

Composite_Score = (RRF_Score * 2.0) + (Vector_Score * 0.5) + (Keyword_Score * 0.3) + (Entity_Matches * 0.1)

Where:
- RRF_Score = Sum( 1.0 / (60 + rank + 1) ) across original and expanded queries
- Vector_Score = 1.0 / (1.0 + Cosine_Distance)
- Keyword_Score = 0.3 for each exact entity match in chunk text
- Entity_Matches = Count of core query entities identified in chunk content
  1. Zero Experience Fabrication: Never invents previous clients, metrics ("scaled to $500K/mo"), or portal counts ("35+ portals").
  2. Strict Source Separation: Always categorizes outputs into (A) Verified Experience, (B) Client Requirements, and (C) Proposed Solutions.
  3. Mandatory Flagging of Missing Data: Flags unverified facts strictly as [CANDIDATE INPUT REQUIRED].
  4. LaTeX Sanitization Engine: clean_latex_artifacts() replaces all raw math delimiters and \rightarrow with unicode arrows (→).

When client requirements cannot be fulfilled by native GoHighLevel features, the assistant generates verified, production-ready custom front-end solutions.

5.1 The Single Page Application (SPA) Challenge

Because GoHighLevel is an SPA, DOM nodes render asynchronously after route changes. The assistant outputs our 5-pillar front-end solution:

/**
 * GoHighLevel Production Frontend Customization Engine (ghl_frontend_customizer.js)
 * Target: Agency Settings -> Custom JS / Sub-Account Custom Code
 */
(function () {
  'use strict';

  // 1. External Script & Web Worker Dynamic Injection (Formula404 Wrapper)
  async function checkforformula404(callback = function () {}) {
    var formula404 = document.createElement('script');
    formula404.id = 'formulaloadedf404';
    formula404.src = "https://scripts.jdfunnel.com/script.php?id=webworker_init404formula";
    formula404.onload = async function () { callback(); };
    if (typeof init_formula_404 === 'undefined' && !document.getElementById('formulaloadedf404')) {
      document.head.append(formula404);
    } else { callback(); }
  }

  // 2. Safe REST API Invocation Bridge
  async function executeGhlApi(endpoint, method = "GET", payload = null) {
    if (typeof rest_api_call === "function") {
      return await rest_api_call(endpoint, method, payload);
    }
    const res = await fetch(`https://services.leadconnectorhq.com/${endpoint.replace(/^\/+/, '')}`, {
      method: method,
      headers: {
        "Authorization": `Bearer ${window.GHL_ACCESS_TOKEN || ''}`,
        "Version": "2021-07-28",
        "Content-Type": "application/json"
      },
      body: payload ? JSON.stringify(payload) : null
    });
    return await res.json();
  }

  // 3. Dynamic UI Customization & Role Permissions Handler
  async function rolesPermission() {
    const isContactDetails = window.location.href.includes("contactsdetails") || 
                             window.location.href.includes("/contacts/detail");
    if (isContactDetails) {
      const headerArea = document.querySelector(".contact-details-header, .action-bar");
      if (headerArea && !document.querySelector("#ghl-custom-btn")) {
        const btn = document.createElement("button");
        btn.id = "ghl-custom-btn";
        btn.className = "btn btn-primary custom-theme-btn";
        btn.innerText = "⚡ Fetch Custom Data";
        btn.onclick = async () => {
          const parts = window.location.href.split("/");
          const contactId = parts[parts.length - 1].split("?")[0];
          const data = await executeGhlApi(`contacts/${contactId}`, "GET");
          alert(`Contact: ${data.contact ? data.contact.name || data.contact.email : 'Success'}`);
        };
        headerArea.appendChild(btn);
      }
    }
  }

  // 4. Debounced MutationObserver (120ms debounce prevents CPU throttling)
  let debounceTimer = null;
  const target = document.querySelector("body");
  const observer = new MutationObserver(() => {
    if (debounceTimer) clearTimeout(debounceTimer);
    debounceTimer = setTimeout(() => { rolesPermission(); }, 120);
  });
  if (target) observer.observe(target, { childList: true, subtree: true });

  // 5. SPA Route Change Listener & History Interceptor
  window.addEventListener('routeChangeEvent', () => { rolesPermission(); });
  (function (history) {
    const pushState = history.pushState;
    history.pushState = function (state) {
      const res = pushState.apply(history, arguments);
      window.dispatchEvent(new Event('routeChangeEvent'));
      return res;
    };
  })(window.history);

  // Bootstrap Initializer
  checkforformula404(async () => { rolesPermission(); });
})();

7 Security, Authentication & Dual Database Persistence

The platform implements robust multi-tenant authentication and a failover-safe dual persistence strategy.

7.1 PBKDF2 Password Hashing & Cryptographic Security

# db.py - Cryptographic Security Functions
def hash_password(password: str, salt_hex: str = None):
    if salt_hex is None:
        salt_hex = secrets.token_hex(16)  # 16-byte cryptographically secure random salt
    salt_bytes = bytes.fromhex(salt_hex)
    pwd_hash = hashlib.pbkdf2_hmac('sha256', password.encode('utf-8'), salt_bytes, 100000)
    return pwd_hash.hex(), salt_hex

def verify_password(password: str, salt_hex: str, expected_hash_hex: str):
    computed_hash_hex, _ = hash_password(password, salt_hex)
    return secrets.compare_digest(computed_hash_hex, expected_hash_hex)

7.2 Dual Database Engine: Turso Cloud & SQLite WAL

  • Primary Cloud Mode (Turso Cloud libSQL): When TURSO_DATABASE_URL and TURSO_AUTH_TOKEN are provided in the environment, queries execute against Turso's distributed HTTP pipeline API (/v2/pipeline).
  • Automatic Local Fallback (SQLite WAL): If Turso credentials are absent or if network connectivity is interrupted, the system automatically and silently falls back to local SQLite with Write-Ahead Logging (ghl_database.db) with zero application downtime.

10 Operational Diagnostics & Troubleshooting Guide

This chapter documents verified operational diagnostic procedures and solutions for common real-world scenarios.

10.1 Diagnostic Runbook

1. Issue: Google Gemini returns "404 NOT_FOUND" or "Model Not Found"
Root Cause: The configured GEMINI_API_KEY does not have the Generative Language API enabled in Google Cloud Console, or the key belongs to an unauthorized enterprise Google Cloud project.
Resolution: Navigate to Google AI Studio, generate a standard API key with default generative permissions, and set it in your .env file or through the UI Settings modal.
2. Issue: High RAM usage or slow initial query latency
Root Cause: PyTorch SentenceTransformers loading full weights on limited CPU instances.
Resolution: The codebase utilizes FastEmbed ONNX Runtime by default (threads=1), consuming only ~50MB RAM. The background warmup thread (_warmup_background in app.py) vectorizes a dummy query at startup, ensuring that the very first user query responds with sub-millisecond vector latency.
3. Issue: Validating Pipeline Retrieval & Prompt Generation
Procedure: Execute the built-in automated test suite: 
python test_rag_pipeline.py
This script executes three automated validation tests: Frontend Customization recognition, System Architecture intent routing, and concise factual query verification.
